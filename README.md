A modern, responsive, 3D animated portfolio website for **Theerthan B G** (BCA Scholar, Tech Innovator, AI & UI/UX Developer from Hassan, Karnataka).

## 🌟 Key Features

1. **3D WebGL Holographic Engine (Three.js)**
   - Morphing holographic wireframe icosahedron with glowing nodes and physical inner crystal.
   - 3-axis orbital cyber rings and interactive camera tracking responsive to cursor and touch.
   - Shockwave / particle pulse on click.
   - Ambient deep-space particle starfield.

2. **Kinetic Typography & GSAP Motion**
   - Live typewriter cycling through your key titles and achievements.
   - Staggered scroll animations and live telemetry stats counter.
   - 3D tilt perspective cards with specular glare reflections (Vanilla-Tilt).

3. **Integrated Profiles & Background**
   - **About / Origin**: BCA Scholar journey from Hassan, Karnataka, core technical passions (AI, Web, UI/UX, Cybersecurity).
   - **Hackathons & Achievements**: Full lightbox modal viewer with actual certificates and photos from *SDM Jhenkar Season 6*, *Confluence 2.0*, *Intellipaat AI Bootcamp*, and *be10x AI Tools Workshop*.
   - **Featured Projects**: Interactive filterable project cards (AI Suite, Theerthan Updates Portal, CyberGuard Sentinel, AgroExport Hub, Nova UI/UX Kit, HackPitch Pro).
   - **Skills Matrix**: Visualized skill proficiency in Web, AI Tools, UI/UX Design, and Core CS.
   - **Theerthan Updates Blog Stream**: Live summary cards with direct links to your blog.
   - **Transmission Terminal / Contact Hub**: Direct links to LinkedIn, Instagram, Blogspot, and GitHub, plus an interactive message form and 1-click email copy button with toast feedback and confetti.

4. **Web Audio API Synth SFX**
   - Futuristic UI audio feedback for hovers, clicks, scans, and transmission dispatch.
   - Sound toggle button with persistent state.

## 🚢 How to Deploy for Free (1-Click)

### Option A: GitHub Pages
1. Create a repository on GitHub (e.g. `theerthan-bg/theerthan-bg.github.io` or `portfolio`).
2. Push all files (`index.html`, `styles.css`, `three-scene.js`, `main.js`) to the repository.
3. In GitHub repo Settings -> **Pages**, select branch `main` / root `/` and click **Save**.

### Option B: Vercel / Netlify
1. Drag and drop the `theerthan-3d-portfolio` folder onto [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
2. Live within 30 seconds!
